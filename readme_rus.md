# SoundSphere — Музыкальная платформа

Платформа для независимых артистов. Дипломный проект по веб-разработке.

## Технологии

Django 6.0, Django REST Framework, Channels, WebSocket (Daphne), JWT (SimpleJWT), PostgreSQL (для тестов используется SQLite3, но его можно заменить в настройках), Swagger, Vanilla JavaScript, CSS (тёмная тема).

Проект можно запустить на локальной машине.

## Установка и запуск

```bash
# 1. Виртуальное окружение
python -m venv venv
venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Миграции
python manage.py makemigrations
python manage.py migrate

# 4. Тестовые данные
python test_data.py

# 5. Создание администратора
python manage.py createsuperuser

# 6. Запуск
.\run.bat
```

Права доступа

- **IsAdmin** — полный доступ (роль admin)
- **IsModerator** — просмотр пользователей, модерация контента (роль moderator)
- **IsArtist** — создание треков и альбомов
- **IsOwner** — редактирование и удаление только своих объектов
- **IsAuthenticated** — лайки, подписки, плейлисты, жалобы
- **AllowAny** — просмотр треков, артистов, альбомов, регистрация

Основные возможности
- Стриминг аудио через WebSocket с буферизацией и авто-реконнектом
- Регистрация с подтверждением email
- Профиль пользователя с редактированием
- CRUD треков, альбомов, артистов, плейлистов
- Поиск по трекам и артистам, фильтрация по жанрам
- Топ треков и плейлистов за неделю 
- Лайки треков, альбомов, плейлистов
- Подписки на артистов
- Система жалоб (защита авторских прав)
- История прослушиваний
- Кнопка "Слушать сейчас" — продолжает с последнего трека
- Тёмная тема, адаптивный дизайн
- Админ-панель Django

Модели
- User — пользователь (роль, аватар, флаг артиста)
- Artist — профиль артиста (имя, био, аватар)
- Album — альбом (название, обложка, дата релиза)
- Track — трек (название, аудиофайл, длительность, обложка, жанр)
- Genre — жанр (название, slug)
- PlayList — плейлист (название, публичный/приватный)
- PlayListTrack — трек в плейлисте
- PlayListLike — лайк плейлиста
- Follow — подписка на артиста
- TrackLike — лайк трека
- AlbumLike — лайк альбома
- ListeningHistory — история прослушиваний
- Report — жалоба на контент
- EmailVerificationToken — токен подтверждения почты

Папка media/ не в gitignore не ошибка
В папке media/ находятся тестовые аудиофайлы и обложки для демонстрации работы плеера. Файлы необходимы для проверки функционала.
