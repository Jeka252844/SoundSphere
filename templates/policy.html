Политика конфиденциальности SoundSphere

Последнее обновление: 31 июля 2026 г.

1. Сбор данных

Мы собираем: имя пользователя, email, аватар, информацию профиля, загруженный контент.

2. Использование данных

Данные используются для функционирования платформы: авторизация, персонализация, стриминг.

3. Файлы cookie

Используются для сохранения сессии и настроек (громкость, язык).

4. Защита данных

Пароли хешируются. Доступ к API защищён JWT-токенами.

5. Авторские права

Артисты сохраняют права на загруженный контент. Платформа вправе удалить контент по жалобе.

Примечание: тестовые треки, загруженные в систему для демонстрации, используются исключительно в учебных целях в рамках дипломного проекта и не предназначены для коммерческого использования.
